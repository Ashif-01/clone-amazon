# clone-amazon# 🛒 Amazon Clone Frontend

A responsive, front-end clone of the Amazon homepage built to demonstrate modern web design principles and UI layout techniques. 

## ✨ Features
* **Interactive Navigation Bar:** Includes a styled search input with category selection and a functional cart counter.
* **Responsive Grid Layout:** Uses CSS Flexbox and Grid to organize product categories and mimic the authentic e-commerce feel.
* **Dynamic Cart Logic:** JavaScript integration to update the shopping cart count in real-time when items are added.
* **Authentic Styling:** Replicates exact brand colors, hover states, and navigational hierarchies.

## 🛠️ Tech Stack
* **HTML5:** For semantic structure.
* **CSS3:** For styling, custom hover effects, and responsive design.
* **JavaScript:** For DOM manipulation and user interactivity.

## 🚀 How to Run Locally
1. Download or clone this repository to your local machine.
2. Open the project folder.
3. Double-click the `index.html` file to view the website directly in your web browser.
